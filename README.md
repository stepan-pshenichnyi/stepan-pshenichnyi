### 🎹 Automatic Piano Exercise Generator

A research-oriented project exploring the intersection of algorithmic music generation and pedagogical constraints.

The system generates piano sight-reading exercises conditioned on ABRSM difficulty grades, combining statistical modelling with explicit musical rules.

**Key concepts:**
- Markov models for melodic generation
- Statistical modelling of rhythmic patterns
- Grade-conditioned difficulty control
- Rule-based pedagogical constraints
- Computational music generation

[Explore the repository →](https://github.com/stepan-pshenichnyi/automatic-piano-exercise-generator)
